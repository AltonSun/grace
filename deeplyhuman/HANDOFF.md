# Handoff: Deeply Human static rebuild

This handoff comes from a Claude Code cloud session. Read this file first.

## What this is
This folder is a static, framework-free rebuild of https://deeplyhuman.eu, the site of Gabrielė Jauniūtė
(ThetaHealing sessions, retreats and rituals, poetry). The original is a Lovable/React app. This copy has
no Lovable code, analytics or hosted assets. Every image is local, in `img/`.

**Goal:** serve it at **https://altonsun.com/deeplyhuman/**. The server is nginx/1.28.0 on Ubuntu.
The site root currently serves `index.html` and `house.css`, and `/deeplyhuman` returns a 404.

## Structure
- `index.html` (home), `about/`, `theta-healing/`, `retreats/`, `poetry/`: each is a plain `index.html`
- `private-sessions/`: meta-refresh redirect to `theta-healing/` (the original URL)
- `assets/site.css`, `assets/site.js`, `assets/favicon.svg`
- All links are relative, so the folder works under any path prefix.
- EN/LT: both languages are in the HTML. `html[data-lang]` and CSS hide one; the choice is saved in
  localStorage key `dh-lang`, the same key as the original.
- The pages were generated by a Python script that isn't included. Edit the HTML directly from now on.
- Every page has `<link rel="canonical">` pointing at deeplyhuman.eu, to avoid duplicate-content SEO.
  Remove those tags if this copy becomes primary.

## Verified in the cloud session
Headless Chromium loaded all five pages at 1280px and iPhone 13 sizes, in EN and LT. There were no JS errors,
no 404s and no horizontal scroll. Accordions, slideshows, the lightbox and the language toggle all work.

## Deploy steps (for the local agent)
1. Find the nginx `root` for altonsun.com (`/etc/nginx/sites-enabled/*`).
2. Copy this folder there as `deeplyhuman/`, without `HANDOFF.md` and `DEPLOY.md`, e.g.
   `rsync -av --delete --exclude '*.md' ./ user@altonsun.com:<root>/deeplyhuman/`
3. The default `try_files $uri $uri/ =404` is enough. Optionally cache `img/` for 30 days.
4. Check that `https://altonsun.com/deeplyhuman/`, `/about/`, `/theta-healing/`, `/retreats/` and `/poetry/` return 200
   and that the images load.
